# Product design

The supplied StegoLab logo is unchanged. Graphite navigation, ivory surfaces, restrained gold, locally bundled Manrope and thin borders retain the established identity.

Home presents the logo, a short description and Embed/Extract actions. Embed uses one carrier drop zone, Text/File selection and optional password protection. Extract requests a password only when a validated encrypted container is discovered. About explains carriers, privacy, limitations and the creator.

Technical choices are automatic. Format details and extraction Details use native disclosures. Focus is visible; controls have semantic labels; reduced-motion preferences are respected. The compact mobile navigation keeps all four destinations accessible. Screenshots in docs/screenshots were captured from the actual static production build at consistent desktop dimensions, with an additional mobile form image.
